## 核心算法(都已实现并验证)

- **速度环**: 增量式 PI + 速度前馈, 5ms, 抗积分饱和; 阶跃上升 60ms、超调 <10%、零稳态误差
- **循迹环**: 位置式 PD + 微分先行 + 微分低通; 灰度加权平均误差, 丢线记忆抢线, 十字检测去抖计数
- **航向环**: 陀螺仪连续角(±180°跳变展开)PD, 用于无引导线直行 / 定角转弯
- **视觉循迹**: OpenMV `get_regression` 线性回归, 偏差 + 线倾角双量(倾角当预瞄前馈)
- **自动降级**: 视觉失联→灰度→陀螺仪, 传感器坏了车不失控
- **弯道自适应降速** + 目标速度斜坡(防打滑) + 里程计(编码器距离 × 陀螺仪航向融合)
- **任务原语状态机**: 循迹N个十字 / 循迹X米 / 盲走X米 / 转到X度 / 精确停车(距离环) / 蜂鸣, 拿到题拼积木即可
- **防御性设施**(2024H 获奖方案套路): 每原语超时兜底(默认15s, 可逐步覆盖)、
  切态统一清 PID 历史、切态短蜂鸣(听声定位卡在哪)、转弯连续10帧判稳、
  角误差最短路径 wrap、p3 现场 trim 字段(逐圈查表补偿)
- **灰度前端**: 逐路归一化 + 噪声地板 + 3点中位值滤波 + 可选非线性误差映射
- **双车协议**(comm/radio_link): AA55 帧头 + 滚动 seq + CRC8, 状态帧广播 +
  事件帧 ACK 重发去重 + 心跳超时判失联, 物理层随便接 HC-05/NRF透传/ESP-NOW 桥

## 快速上手(移植 4 步)

1. **建工程**: CCS 导入 MSPM0G3507 空例程(SDK 的 `empty` 工程), 把 `firmware/` 整体拷进去;
2. **配外设**: 用 `bsp/car_mspm0g3507.syscfg` 替换工程里的 `empty.syscfg`, SysConfig GUI 打开一次: 若有引脚标红按提示解决冲突, 保存生成代码(实例名已与代码对齐, 不要改 $name); 同时把链接文件(ticlang `device_linker.cmd` / gcc `device_linker.lds`)里 FLASH 的 length 从 `0x00020000` 改为 `0x0001FC00`, 给参数区留出最后 1KB 扇区;
3. **编译**: 工程属性定义编译宏 `TARGET_MSPM0` 后编译。`bsp_mspm0.c` 的 driverlib 调用已对照 SDK 2.11.00.07 真头文件校验过, 正常应零报错; 若你自己改过实例名, 顺着编译报错对齐即可;
4. **改参数**: `bsp_config.h` 里按实车填 3 个机械参数(每转计数/轮径/轮距) — **不填对, 速度和距离全是错的**。注意编码器是 GPIO 中断 2 倍频方案, 每转计数 = 线数×2×减速比(不是×4)。

上电自检顺序见 `docs/TUNING.md`: 先验证编码器方向 → 电机方向 → 灰度校准 → 再上闭环。

## 调参(比赛现场不接电脑)

- 4 键 + OLED 菜单: 所有 PID 参数现场可调, KEY1 长按存 flash 掉电不丢;
- 蓝牙(接 UART0)+ VOFA+ 上位机: JustFloat 8 通道曲线(左右轮速/目标速/线误差/yaw/PWM/任务步), 也可发 `p1=1.25` 这类命令改参数、`r`/`s` 启停;
- 详细整定流程(含各参数起步值和现象对照表)见 `docs/TUNING.md`。

## 已知的坑(前人流血换的)

0. G3507 **只有 TIMG8 一个硬件 QEI**, 双编码器都走 GPIO 中断软件解码(2025 年真车同款方案); 占空比在 SysConfig 默认极性下是反的(cc 越大 duty 越小), `bsp_mspm0.c` 已按此实现，移植时须结合当前 TI SDK 头文件和示波器复核;
1. 编码器一侧装反是最常见"上电就疯", 先开环验证 `bsp_encoder_*` 前进时都递增; 方向不对改 `bsp_config.h` 的 `CFG_ENC_*_SIGN` / `CFG_MOTOR_*_SIGN`;
2. 灰度**每换一个场地必须重新校准**(菜单里 CAL GRAY: 白地按一下, 黑线按一下);
3. JY61P 上电前 3 秒别动车(自校准); 电机电源和逻辑电源必须分开稳压, 共地;
4. OpenMV 现场第一件事锁曝光/白平衡再调阈值, 否则赛场灯光让你怀疑人生;
5. `pid_inc` 输出是 PWM 占空比, 电池电压掉了等效增益跟着掉 — 比赛日用满电电池调参。
