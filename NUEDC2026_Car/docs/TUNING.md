# 调参手册 (按顺序执行, 不要跳步)

## 0. 上电自检(开环, 每次改硬件后必做)

1. 架起车轮, 手转左轮向前 → OLED/VOFA 看 `enc_l` 递增; 右轮同理。反了就在
   `bsp_mspm0.c` 编码器函数里取负;
2. `bsp_motor_set(0.2, 0.2)` 两轮都向前转; 反了翻方向脚逻辑;
3. 灰度校准: 车放全白处菜单执行 CAL WHITE, 压黑线执行 CAL BLACK,
   看 `err` 在线中央≈0, 左偏为负右偏为正(反了把传感器排线倒过来或权重取反);
4. JY61P: 静止 yaw 漂移 < 0.5°/min; 手转车 90° 读数跟着变 90°。

## 1. 速度环(架空车轮 → 放地)

VOFA 看 ch0/ch1(实际轮速) vs ch2(目标)。发 `p8=0.5` 设 0.5m/s 巡航, `r` 启动。

| 现象 | 动作 |
|---|---|
| 上升慢, 到不了目标 | Kf 加大(先调前馈! 0.4→0.7 试) |
| 有稳态差 | Ki 加大 (0.05 步进) |
| 振荡/电机啸叫 | Kp 减小, 或 Ki 太大 |
| 起步猛冲翘头 | Ramp 减小 (v_ramp_step) |

目标: 阶跃上升 <150ms, 超调 <10%, 稳态误差 <0.02m/s。左右轮参数保持一致。

## 2. 循迹环(先低速 0.5m/s)

| 现象 | 动作 |
|---|---|
| 回线慢, 弯道外甩 | Line Kp 加大 |
| 直线上蛇形摆动 | Line Kd 加大; 还摆则 Kp 减小 |
| 小幅高频抖动 | 灰度 lpf_alpha 减小(0.6→0.4), 或 Kd 的低通 d_lpf_alpha 减小 |
| 直角弯冲出去 | SlowK 加大(弯道降速), 或提高传感器前瞻距离(硬件前移) |

稳定后逐步加速: 0.5 → 0.8 → 1.2 → 1.5, 每档重新微调 Kd。

## 3. 航向环

原地转 90° 测试: 过冲则 Yaw Kd 加大; 到不了位则 Yaw Kp 加大;
盲走 2m 粉笔画直线对比, 漂移 >3cm 检查陀螺仪安装(必须水平、远离电机)。

## 4. 距离环(精确停车)

`MI_STOP_AT` 的 pid_dist Kp=4 起步: 停过头 → 减小; 爬得太慢 → 加大。
最终标准: 1m/s 进入, 停车误差 ±2cm 内。

## 5. 视觉(OpenMV)

1. IDE 里先锁曝光/白平衡(脚本已写), 再调 `GRAYSCALE_THRESHOLD` 直到二值图黑线干净;
2. 确认帧率 ≥50fps(QQVGA), 低了缩小 ROI;
3. 主控端把菜单/命令切到 SRC_VISION, 从 0.5m/s 起调 Line Kp/Kd(和灰度共用);
4. `vision_angle_k` 从 0.01 起加, 弯道提前打角明显但不抖为佳;
5. 拔掉 OpenMV 线跑一圈, 确认自动降级到灰度, 车不失控。

## 6. 赛前最后一晚

满电电池重校所有参数 → KEY1 长按存 flash → 断电重启验证参数还在 →
全流程跑 10 次记成功率, <8 次的环节降速处理。比赛拼的是稳定, 不是极速。
