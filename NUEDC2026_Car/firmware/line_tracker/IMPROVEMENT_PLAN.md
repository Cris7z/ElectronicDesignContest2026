## 2. 完善目标

按优先级排列：

1. 消除直线时基础速度周期性升降造成的“踩油门感”。
2. 保持当前弯道流畅性，不因直线优化而降低入弯能力。
3. 减少单帧灰度毛刺、瞬时全白和瞬时宽黑造成的输出突变。
4. 修复左右轮独立限幅吃掉差速的问题。
5. 用左右轮独立速度 PI 替换当前 100 ms 相对均衡器。
6. 让实际轮速在电池电压和地面负载变化时仍能稳定跟踪目标。

## 3. 暂不纳入本轮的内容

- 循迹外环积分；循迹 I 继续保持 0。
- OLED、MPU6050、K230、蓝牙和任务状态机。
- 起终点、圈数、里程和计时。
- 基于 m/s 的正式速度单位；CPR、轮径和减速比未完成实测前先用编码器计数。
- PWM 频率调整；它不是当前低频油门抽动的首要原因。
- 电池电压前馈；待双轮速度 PI 稳定后再评估。

## 4. 总体实施原则

1. 一次只引入一类控制变化。
2. 每阶段均执行主机测试、目标编译、架空检查和赛道验收。
3. 每阶段建立独立构建目录和备份，不覆盖上一个稳定版本。
4. 当前 P、I、D 在前三阶段不修改。
5. 速度目标稳定之前不启用速度 PI。
6. 旧的 100 ms 均衡器与新的双轮速度 PI 不同时生效。
7. 烧录按现有流程执行，不增加程序读回校验。

## 5. 阶段 A：平滑基础速度调度

目标：只消除两轮共同加减速的抽动，不改变循迹转向控制器。

实施状态：已于 2026-07-31 编译并烧录 `line_tracker_straight_smooth_20260731`，
其后为补偿小误差区速度提高导致的慢 S 摆，仅将 `yaw_gain_min` 从 0.60 逐步调为 0.90，
最新烧录目标为 `line_tracker_straight_smooth_yaw90_20260731`；等待赛道直线与弯道验收。

### 5.1 当前问题

当前基础速度使用：

```text
speed_weight = max(abs(raw_yaw_error), abs(filtered_yaw_error))
target = VMAX / (1 + 4 * speed_weight / 7)
```

因此未滤波误差可以直接降低基础速度。按现有参数：

| 误差权重 | 目标占空比 |
|---:|---:|
| 0 | 51.75% |
| 0.5 | 40.25% |
| 1 | 32.93% |
| ≥3 | 23% |

黑线从 R3/R4 中间轻微移动到任一中央探头时，权重可以从 0 接近 1；这属于正常直线
位置变化，却会触发近 19 个百分点的目标速度变化。当前又是快速减速、慢速恢复，因而
容易形成锯齿状油门。

### 5.2 计划改动

增加只服务于速度调度的状态：

```text
speed_weight_lpf
speed_filter_seeded
```

计划初值：

```text
speed_filter_alpha       = 0.20
speed_deadband_weight    = 1.00
speed_full_slow_weight   = 4.00
speed_accel_step         = 0.005
speed_decel_step         = 0.008
```

速度计算改为：

```text
sample = abs(raw_yaw_error)
speed_weight_lpf += 0.20 * (sample - speed_weight_lpf)
t = smoothstep(speed_weight_lpf, 1.0, 4.0)
target = VMAX + (VMIN - VMAX) * t
```

约束：

- 原始误差只作为低通输入，不再直接影响占空比。
- 权重不超过 1 时保持最高速度。
- 权重 1 至 4 之间连续降速。
- 权重达到 4 后保持最低速度。
- 横线、搜线和故障仍使用各自的安全速度逻辑。

### 5.3 灰度质心门槛软化

黑线状态判断继续使用原始 `strength` 和 600/400 迟滞；仅质心计算改为：

```text
centroid_strength = max(strength - 150, 0)
```

这样强度从 149 变为 150 时不会突然把完整的 150 权重加入质心。

### 5.4 阶段 A 测试

主机测试至少覆盖：

- R3/R4 强度相等时速度保持最高值。
- 只压 R3 或 R4 时仍处于直线速度区。
- 单帧权重毛刺不会造成明显速度下降。
- 持续权重 4 时能在约 180 ms 内降到最低速度。
- 误差恢复后按 0.5%/tick 平滑加速。
- P、I、D 和左右转向方向未改变。

实车验收：

- 长直线不再出现明显共同收油、补油。
- 弯道仍能及时降速。
- 弯道轨迹和当前基线相比无明显退化。

阶段 A 计划构建名：`line_tracker_straight_smooth`

## 6. 阶段 B：状态抗毛刺与保差速限幅

目标：避免单帧状态变化和独立限幅向电机注入新的阶跃。

实施状态：已于 2026-07-31 编译并烧录
`line_tracker_state_saturation_yaw90_20260731`。其中联动限幅在急弯中会使内轮短暂反转、
引发抖动，已撤销；保留光学状态确认，恢复版本为
`line_tracker_state_debounce_yaw90_20260731`。

### 6.1 光学状态确认

把“ADC 总线无效”和“有效 ADC 下暂时看不到黑线”严格区分：

- `line_valid == false`：立即进入安全停车/故障路径，不允许继续驱动。
- `line_valid == true && black_count == 0`：连续 3 帧后才进入搜线。
- `line_valid == true && black_count > max_track_black_count`：连续 2 帧后才进入宽线模式。
- 确认窗口内保持上一拍有效控制状态，不立即把基础速度重置为 23%。

连续质心误差本身不增加多帧确认，避免给转向环引入额外相位滞后。

### 6.2 保差速联动限幅

当前左右轮各自裁剪会在一侧触顶时缩小预期轮速差。计划改为共同平移：

```text
left  = base - yaw
right = base + yaw

若 max(left, right) > limit：
    两轮同时减去超出量

若 min(left, right) < -limit：
    两轮同时加上超出量
```

只要请求的左右差没有超过硬件可实现范围，该方法保持 `right-left` 不变。

### 6.3 100 ms 均衡器判断

阶段 B 仍保留现有均衡器。若直线仍存在严格约 10 Hz 的小台阶，再制作一个只旁路
均衡器的 A/B 固件；不在旧均衡器上继续投入复杂调参，因为它最终会被速度 PI 替换。

### 6.4 阶段 B 测试

- 一帧全白不会立即进入搜线。
- 连续全白达到确认门槛后正常搜线。
- 无效 ADC 帧立即安全停车。
- 一帧宽黑不切换，连续宽黑正常进入宽线模式。
- 正、负转向饱和时左右轮差保持不变。
- 限幅后的两个输出始终处于允许范围。

阶段 B 计划构建名：`line_tracker_state_saturation`

## 7. 阶段 C：双轮速度 PI 影子模式

目标：先验证测速、目标和 PI 数学，不接管电机。

### 7.1 控制结构

```text
灰度外环：每 5 ms 产生 q_left / q_right
        ↓
累计 4 拍目标和编码器增量
        ↓
速度内环：每 20 ms 更新一次左右 PI
        ↓
影子模式只记录结果，不修改实际 PWM
```

`q_left/q_right` 暂沿用现有归一化输出范围，语义逐步从“直接 PWM”过渡为“目标轮速”。

### 7.2 临时无单位速度标尺

使用当前固定 45% 架空测量：

```text
左轮约 3685 count/s
右轮约 3661.5 count/s
平均增益约 8162.8 count/s/归一化指令
C20 = 163.256 count/20ms/归一化指令
```

临时目标：

| 归一化目标 | 20 ms 目标计数 |
|---:|---:|
| 0.08 | 13.1 |
| 0.23 | 37.5 |
| 0.45 | 73.5 |
| 0.5175 | 84.5 |

架空单点标尺只用于第一轮闭环验证。正式赛道参数需在相同地面和电量下补测
23%、35%、45% 三点，再修正前馈曲线。

### 7.3 编码器方向

- 左轮前进计数：`-(left_now - left_last)`
- 右轮前进计数：`+(right_now - right_last)`

进入 PI 前两轮统一为“物理前进为正”。

### 7.4 PI 形式

```text
target_norm   = 四拍目标平均值
measured_norm = LPF(measured_count / C20)
error         = target_norm - measured_norm

correction = Kp * error + integral
pwm = feedforward(target_norm) + correction
```

影子模式计划参数：

```text
更新周期             = 20 ms
速度测量低通 alpha   = 0.50
Kp                   = 0.30
Ki                   = 0
积分限幅             = ±0.04
修正限幅             = ±0.03
```

### 7.5 抗积分饱和与复位

正式加入 `Ki` 前必须具备：

- 输出顶到上限且误差仍要求继续增大时，拒绝本拍积分。
- 误差反向时允许积分回吐。
- WAIT、FAULT、零目标时清零两轮状态。
- 每个轮子目标方向改变时单独清零该轮状态。
- 目标绝对值低于 0.10 时暂不启用 PI。

### 7.6 编码器失效保护

当某轮目标绝对值不低于 0.15，且连续约 250 ms 几乎无前进计数时：

1. 禁止该轮 PI 继续把 PWM 推高。
2. 关闭两轮驱动并进入故障。
3. 记录左右目标、实测计数及失效轮。

## 8. 阶段 D：正式启用双轮速度 PI

目标：逐步让 PI 接管速度修正，替换旧均衡器。

### 8.1 架空 P-only

第一轮：

```text
Kp             = 0.30
Ki             = 0
修正限幅       = ±0.03
前馈           = 当前 q_left / q_right
旧 100 ms 均衡 = 禁用
```

检查：

- 左右轮修正方向正确。
- 目标升高时 PWM 不会反向降低。
- 没有持续正负交替的极限振荡。
- 停止和换向时不残留修正。
- BSP 原有 5 ms 换向滑行保护正常生效。

### 8.2 下赛道加入 I

P-only 稳定后：

```text
Ki 初值        = 0.30/s
Ki 最大试验值  = 0.50/s
积分限幅       = ±0.04
总修正限幅     = 先 ±0.03，最终不超过 ±0.06
```

调节顺序：

1. 保持 `Ki=0` 调整 Kp，使速度误差能收敛但不振荡。
2. 加入 `Ki=0.30/s` 消除持续负载误差。
3. 只有仍存在稳定误差时才逐步增加 Ki。
4. 若输出出现低频来回摆动，先减 Ki，再考虑减 Kp。

### 8.3 删除旧均衡器

阶段 D 已删除：

- `balance_wheel_speed()`
- `RIGHT_ENCODER_RATE_SCALE`
- `WHEEL_BALANCE_KP/KI`
- 旧共同积分与 trim 状态

不保留两套会同时作用于 PWM 的速度调节器。

阶段 D 计划构建名：`line_tracker_speed_pi_active`

## 11. 最终验收标准

全部满足才建立新的稳定版：

1. 直线没有肉眼可见的周期性共模油门脉冲。
2. `(left+right)/2` 对单帧灰度扰动没有明显阶跃。
3. 弯道流畅性不低于当前基线。
4. 稳态左右轮速度误差控制在约 5%～8%以内。
5. PI 修正不长期顶在 ±6%。
6. 不出现固定 20 ms 或 100 ms 的低频振荡。
7. ADC 无效和控制周期超时均能安全停车；编码器断线保护不在本轮范围。
8. 主机测试、TI 目标编译均通过。
9. 已由操作者确认实车赛道回归通过；随后创建 ZIP 备份和 Git 提交。
