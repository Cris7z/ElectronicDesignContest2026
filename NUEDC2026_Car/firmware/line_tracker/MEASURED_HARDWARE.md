# Line tracker：实测冻结记录

本工程只服务当前 C07A / MSPM0G3507 + D103A/TB6612 底盘。它不包含球杆、视觉、
蓝牙、MPU6050 姿态、整圈计时或终点逻辑。

| 项目 | 实测/冻结值 |
|---|---|
| 左电机 | TB6612 B：PB3/TIMA1_CCP1、PA16/PA17；正占空比为物理前进 |
| 右电机 | TB6612 A：PB2/TIMA1_CCP0、PA14/PA13；正占空比为物理前进 |
| BLS | PA18，R8=47 kΩ 下拉；松开=0、按下=1；短按松手启动/复位，长按约1 s 停车 |
| LED | PB9 |
| 灰度地址 | PA12=AD2、PA27=AD1、PB16=AD0；000..111 对应 R0..R7 |
| 灰度 ADC | PB17 / ADC1_A1_4；R0 在车头朝向的左侧 |
| 灰度极性 | 黑线高；白底约 171..174，黑线 4095 |
| 横向坐标 | R0..R7 = -35,-25,-15,-5,+5,+15,+25,+35 mm |
| 标定记录 | 白=[174,174,172,173,171,172,171,171]；黑全为4095；CRC=0x74D9 |
| 控制周期 | TIMG7，5 ms；整帧扫描预算≤1.2 ms |
| PWM 极性 | TIMA1 的 TB6612 有效高时间为 `(period-compare)/period`；不能直接写 `compare=duty×period` |
| 低速扫档 | 架空 0.5 s：2–5% 两轮近乎 0；6% 左=-123、右=0；8% 左=-254、右=238；10% 左=-343、右=357 编码器计数 |

安全边界：CD4051 为 5 V 供电但 `OUT` 不得超过 MSPM0 的 VDD；若地址线 3.3 V
逻辑裕量不足，先加 74AHCT125。更换灰度板、调整安装高度或增加 OUT 分压后，必须重新
测量白/黑值并更新 `app/main.c` 的 `k_config`。
