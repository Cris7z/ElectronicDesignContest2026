## 阶段门禁

1. 当前阶段只能维护 `H-R02` 的资料、接线/IO 和既有代码基线；不以“将来会用”提前增加 D36A/K230 代码。
2. H-R03 以前，D36A 必须保持未接入 MSPM0 正式 IO；其供电、拨码、电机额定电流、线束和失能态要有台架记录。
3. H-R01 以前，K230 只能作为已调研硬件；5 V 供电、实际 RAM、相机型号、通信方式和记录存储链路必须先确认。
4. 每次状态变为 `VERIFIED` 时，新增可复现的验收记录，至少包含日期、配置、原始数据/视频位置、结果和异常。
