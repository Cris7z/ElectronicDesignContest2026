# C07A V1.1 + S27F 当前纯循迹硬件技术文档

> 适用范围：已冻结的 `c07a-line-tracker-preferred-20260731` 纯循迹工程；C07A **V1.1** 核心板与用户确认的 **S27F** 模块化底板。
>
> 本文是原理图与已验证代码基线的对应说明，不是最终接线表，也不为 D36A、K230 或其他未来模块分配 IO。

## 1. 确认范围

| 项目 | 已确认事实 | 不在本文冻结 |
|---|---|---|
| 控制器 | TI MSPM0G3507 的 C07A V1.1 核心板 + S27F 底板。 | 非循迹外设的最终使用方案。 |
| 动力驱动 | D103A / TB6612 双路直流电机驱动。 | 电机具体参数、线束颜色和堵转电流。 |
| 循迹传感器 | 5 V 供电的 CD4051 八路模拟灰度模块。 | 更换模块后的电平裕量、安装高度与重新标定结果。 |
| 启动和指示 | BLS 使用 PA18；状态 LED 使用 PB9。 | 其他 UI 功能。 |

## 2. 真值优先级

1. 当前基线提交的 `firmware/line_tracker/MEASURED_HARDWARE.md` 是**当前循迹功能和极性**的实测冻结记录。
2. S27F 原理图是**底板连接器网络和供电拓扑**的来源。
3. S27F 资源分配表是厂家给出的**默认外设占用建议**；它不限制 MSPM0 在软件中为同一物理管脚选择合法的其他外设复用。
4. C07A V1.1 原理图是核心板版本专属结论的来源。

因此，资源表中把 PB2/PB3 标作 `TIMG6`，与基线把 PB2/PB3 配为 `TIMA1_CCP0/1` 不构成硬件接线冲突。对当前工程，应以基线已经实测的 `TIMA1` PWM 配置为准。

## 3. S27F 底板：当前涉及的连接器网络

下表把原理图中的端口网络转换为可检索文字。这里只列当前循迹直接相关或会影响其安全的网络。

| 原理图区域 / 接口 | 连接到 MSPM0 的网络 | 当前用途或约束 |
|---|---|---|
| TB6612 驱动模块 H9 | 12 V、5 V、GND、`AO1`、`AO2`、`BO2`、`BO1` | 厂家为 TB6612 模块定义的接口网络；必须结合模块线束和实物确认最终针脚对应。 |
| TB6612 驱动模块 H12 | `PB2`、`PA14`、`PA13`、5 V、`PA16`、`PA17`、`PB3`、GND | 控制器侧的 TB6612 接口网络；不得仅根据排针编号推断左右轮。 |
| 电机输出与编码器 J1/J2 | A 路：`PA25/PA26` 编码器；B 路：`PB20/PB24` 编码器 | 当前软件的编码器方向与轮侧归属由基线记录冻结；线束/插头变更后必须重新验证。 |
| CCD 巡线接口 CN2 | `PA22`、`PA9`、`PA27`、3V3、5V、GND | 厂家底板的通用 CCD 接口，**不等于**当前 CD4051 灰度模块的最终线序。 |
| 12 V 转 5 V 模块接口 H15/H16 | 12 V、5 V、GND | P03B 所在的逻辑供电路径；未来 K230 是否可共用尚未验证。 |
| BLS / LED（核心板资源） | `PA18` / `PB9` | PA18 是启动键，PB9 是状态 LED。 |

## 4. 当前纯循迹的已验证逻辑资源

这些数值来自基线的实测冻结记录，而非对新硬件的推测。正式 IO 占用表将在所有硬件资料完成后另建。

| 功能 | MSPM0 资源 | 已验证行为 |
|---|---|---|
| 左轮 PWM / 方向 | TB6612 B：`PB3/TIMA1_CCP1`，`PA16/PA17` | 正占空比为物理前进。 |
| 右轮 PWM / 方向 | TB6612 A：`PB2/TIMA1_CCP0`，`PA14/PA13` | 正占空比为物理前进。 |
| 左、右编码器 | 左轮 B 路编码器、右轮 A 路编码器 | 底板网表中 B 路为 `PB20/PB24`、A 路为 `PA25/PA26`；前进符号为左 `-1`、右 `+1`。 |
| 灰度通道选择 | `PA12=AD2`、`PA27=AD1`、`PB16=AD0` | 二进制 `000...111` 对应 R0...R7。 |
| 灰度 ADC | `PB17 / ADC1_A1_4` | 黑线高；R0 为车头朝向的左侧。 |
| 启动键 | `PA18` | 外部 47 kΩ 下拉；松开 `0`、按下 `1`。 |
| 状态 LED | `PB9` | 当前循迹状态提示。 |
| 控制定时 | `TIMG7`，5 ms | 整帧灰度扫描预算不超过 1.2 ms。 |

## 5. TB6612 原理图的可读化摘要

| TB6612 网络 | 作用 | S27F 侧对应 |
|---|---|---|
| `PWMA` / `PWMB` | A / B 路 PWM 调速 | 当前分别由 `PB2` / `PB3` 输出。 |
| `AIN1` / `AIN2` | A 路方向 | 当前为 `PA14` / `PA13`。 |
| `BIN1` / `BIN2` | B 路方向 | 当前为 `PA16` / `PA17`。 |
| `STBY` | 驱动待机控制 | D103A 原理图将其接至模块逻辑网络；当前代码不把它当作独立控制资源。 |
| `VM` | 电机电源 | 来自 12 V 动力侧，不能与逻辑 5 V 混淆。 |
| `VCC` | 驱动逻辑供电 | 与模块逻辑供电相关，变更前须实测。 |

TB6612 的 A/B 通道名称只是芯片通道，**不等于车体左右**。本车物理左轮使用 B 路、物理右轮使用 A 路，已由 Q-002 关闭确认。

## 6. CD4051 八路灰度模块的安全记录

| 项目 | 当前结论 |
|---|---|
| 供电 | 模块为 5 V 供电。 |
| 控制 / 输出 | 使用三根地址线选择 R0...R7，模拟输出进入 PB17 ADC。 |
| 极性 | 黑线高，白底约 171–174，黑线标定值为 4095（现有标定记录）。 |
| 风险 | CD4051 的 `OUT` 不得超过 MSPM0 的 VDD；地址 3.3 V 逻辑裕量不足时，先加 74AHCT125，再重新标定。 |
| 不可复用约束 | 不得因 S27F 的“CCD 巡线”通用端口名称而擅自改接当前灰度模块；正式线序以后续接线实物核对表为准。 |

## 7. C07A V1.1 的版本依据

厂家识别图显示：V1.1 底部为 `RESET` 与 `BLS` 两个按键；V1.0 另有 `USER` 键，共三个按键。用户确认实物有两个按键，因此核心板版本为 V1.1。

厂家更新记录给出的 V1.1 相对 V1.0 的变更：取消独立 USER 按键、以 BLS 代替；引出 IO 在原有 ESD 基础上增加串联 20 Ω 限流；更换 LDO；调整布线；将 PB8/PB18/PB19 引出至右上角。
