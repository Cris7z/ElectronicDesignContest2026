# D36A V1.1 双路步进电机驱动技术文档

> 适用实物：WHEELTEC D36A **V1.1**。  
> 当前阶段：未来球杆执行器资料；**未接入当前循迹车，未分配 MSPM0 IO，未写驱动。**  
> 最后核对：2026-07-31。

## 1. 结论摘要

- 用户提供的正反面实物照片及厂家“不同版本 D36A 识别方法”图一致，版本为 **V1.1**。
- V1.1 相比 V1.0 的硬件变更为：增加输入控制信号 ESD 保护、增加电源 TVS；尺寸孔位和控制使用方式不变。
- D36A 是双路驱动器，控制接口同时提供电机 1 与电机 2；细分和限流拨码由两路共同使用，不能为两路独立设置。
- `ST1/ST2` 为上升沿有效的步进输入；`EN1/EN2` **低电平休眠，高电平使能**；`DIR1/DIR2` 控制方向。
- 当前球杆设计只预留电机 1 通道的未来用途；在 C07A 上重新分配并完成失能安全验收前，禁止接入。

## 4. 电源、功率与安全边界

| 项目 | 结论 | 当前约束 |
|---|---|---|
| 输入电源 | 资料原理图标为 12-45 V DC 输入。 | 未来必须按电池、电机和热设计实测确认，不能直接从 C07A 逻辑电源取电。 |
| 驱动芯片 | 双 ATD5984。 | 风扇、散热片和芯片发热均应纳入台架验收。 |
| 电机输出 | `A+ / A- / B+ / B-`，两路独立。 | 接线以电机线圈对实测为准；万用表测高速输出波形不能替代示波器。 |
| 逻辑供电 | 控制接口提供 5 V 输出，板上另有 3.3 V。 | 当前不把其 5 V/3.3 V 作为 C07A 或 K230 供电来源。 |
| 公共地 | 控制 GND 必须与控制 MCU 共地。 | 动力回流不得经过 C07A/K230 信号地。 |
| 串联电源输出 | 有与输入并联的电源输出端。 | 当前禁止把它作为未经验证的整车分配节点。 |

## 5. 控制接口

实物背面控制排针丝印与厂家表一致：

| 电机 2 侧 | 含义 | 电机 1 侧 | 含义 |
|---|---|---|---|
| `GND` | 控制地 | `GND` | 控制地 |
| `ST2` | STEP，上升沿有效 | `ST1` | STEP，上升沿有效 |
| `DIR2` | 方向 | `DIR1` | 方向 |
| `EN2` | 低电平休眠，高电平使能 | `EN1` | 低电平休眠，高电平使能 |
| `ADC` | 输入电源电压的 1/11 监测输出 | `5V` | 板上 5 V 输出 |

控制规则：

- `STx` 必须产生上升沿；恒定高或低不能使电机步进。
- `DIRx` 的“正方向”仅表示驱动输出顺序；球杆机构正负方向必须在装车后实测并写入软件配置。
- 上电、复位、故障和急停时，`ENx` 必须保证为低电平；只有通过台架安全检查后才能拉高。
- `ADC` 的量程、电平和 MCU ADC 保护方案尚未核验，当前不接入。

## 6. 六位拨码开关

拨向板上 `ON` 标记为导通，记为 `1`；未导通记为 `0`。该数字是拨码状态，**不是** MS 引脚高低电平。

### 6.1 细分：1/2/3 号拨码（MS1/MS2/MS3）

| MS1 | MS2 | MS3 | 细分 |
|---:|---:|---:|---|
| 1 | 1 | 1 | 不细分 |
| 0 | 1 | 1 | 2 步细分 |
| 0 | 1 | 0 | 4 步细分 |
| 1 | 0 | 0 | 8 步细分 |
| 0 | 0 | 0 | 16 步细分 |
| 1 | 0 | 1 | 32 步细分 |

### 6.2 限流：4/5/6 号拨码（CUR1/CUR2/CUR3）

| CUR1 | CUR2 | CUR3 | 等效电流 |
|---:|---:|---:|---:|
| 0 | 0 | 0 | 1.44 A |
| 0 | 0 | 1 | 1.22 A |
| 0 | 1 | 0 | 0.93 A |
| 0 | 1 | 1 | 0.83 A |
| 1 | 0 | 0 | 0.77 A |
| 1 | 0 | 1 | 0.70 A |
| 1 | 1 | 0 | 0.59 A |
| 1 | 1 | 1 | 0.55 A |

首次台架测试从最小电流 `111 = 0.55 A` 开始，只能在不超过电机额定电流、温升合格且力矩足够的前提下逐档提高。

## 7. 当前项目中的资源状态

| 信号 | 当前 MSPM0 分配 | 状态 | 原因 |
|---|---|---|---|
| `ST1` | 未分配 | 禁止接入 | 当前循迹 TB6612 已使用 TIMA1 PWM。 |
| `DIR1` | 未分配 | 禁止接入 | 当前纯循迹的 TB6612 方向资源已占用候选旧引脚。 |
| `EN1` | 未分配 | 禁止接入 | 必须先设计复位时的硬件/软件失能态。 |
| `ADC` | 未分配 | 禁止接入 | 电压比例、电平和 MCU 输入保护待验证。 |
| `ST2/DIR2/EN2` | 未分配 | 不使用 | 当前 H 题首版不计划使用第二路。 |

本表是“禁止占用”记录，不是未来 IO 方案。

## 8. 后续台架验收清单

1. 断电读取六位拨码位置，形成永久记录。
2. 确认 42 型电机与编码器的完整型号、每相额定电流、线圈对、出线定义和逻辑电平；不得把未核实的 `MS42CG` 当作型号。
3. 仅接动力与电机，在 `EN=0` 时确认无保持力/无异常发热。
4. 在最低限流档下验证 `EN` 低休眠、高使能和 `ST` 上升沿步进。
5. 示波器检查 `ST/DIR/EN` 电平、脉宽、频率和复位安全态。
6. 校验实际步数、方向、细分、温升和噪声。
7. 最后才讨论 MSPM0 引脚、MS42CG 闭环和整车接入。
