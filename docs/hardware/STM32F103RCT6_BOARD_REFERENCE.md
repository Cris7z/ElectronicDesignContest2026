## 2. 关键结论

1. 用户已确认实物主芯片为 **STM32F103RCT6**，后续新工程目标必须是 `STM32F103RC`，LQFP-64、高密度系列。
2. 厂家原理图与 BOM 却将 U1 标为 `STM32F103RE`。`RC` 与 `RE` 的封装、GPIO 和主要外设相同，但 Flash 容量不同；资料包不能覆盖实物丝印。
3. 厂家 LCD 示例错误地配置为 `STM32F103C8`、`64 KiB Flash`、`20 KiB SRAM`，并加入 `startup_stm32f10x_md.s`。**禁止**把它作为本项目的芯片、Flash 算法、启动文件、内存布局或 IO 真值。
4. 因上述矛盾，首次上电/下载时必须读取并记录实物芯片丝印与调试器识别的芯片 ID/Flash 容量；在记录前不得使用“RE”的容量假设。

## 3. 板载资源（原理图已见，尚未实物复核）

| 资源 | 原理图事实 | 阶段 2 处理规则 |
|---|---|---|
| 主时钟 | `X1=8 MHz`，接 `OSC_IN/OSC_OUT`。 | 最小工程先测实际系统时钟，不假定厂商示例中的 `12 MHz` 配置。 |
| 低速时钟 | `X2=32.768 kHz`，接 `PC14/PC15`。 | 未实测前不将 LSE 作为控制周期依赖。 |
| SWD | `PA13/SWDIO`、`PA14/SWCLK` 接 4 针 `JP5`，同口还有 `3V3`、`GND`。 | 首选 ST-Link SWD 下载；禁止把 PA13/PA14 分给普通业务 IO。实际排针物理顺序须以板上丝印/照片复核。 |
| 启动/复位 | `BOOT0`、`BOOT1/PB2` 有下拉；有 RESET 网络和复位按键。 | 默认从主 Flash 启动仍需实测；PB2 在启动相关状态确认前不分配。 |
| USB 转串口 | CH340C 接到 `PA9/USART1_TX`、`PA10/USART1_RX`。 | USART1 预留为调试日志候选；接入外部通信前先确认不会与 CH340 冲突。 |
| 双 Micro-USB | 厂家说明：一个经 CH340 用于 USB-TTL/ISP，另一个接 MCU USB；后者不会自动成为可用串口。 | 首次测试必须确认两个接口的物理丝印和功能；原生 USB 暂不用于本项目。 |
| 板载 3.3 V | 原理图为 `AMS1117-3V3`，由板上 5 V 网络供电。 | 不以资料推断可供 D36A、K230 或整车的电流能力；外设供电另行测量。 |
| 外部 SPI Flash | `25Q16` 使用 `PC0...PC3` 网络。 | 这些引脚视为板载占用候选，正式复核前不分配。 |
| GPIO 引出 | 两侧各一组 `2×16` 排针，原理图列出 PA、PB、PC、PD2、电源与地。 | 已知“有引出”不等于已确认针序；实际接线前查板上丝印并测通。 |

## 4. LQFP-64 外设能力（芯片族事实，不等于项目分配）

| 项目后续需求 | 可用能力方向 | 当前结论 |
|---|---|---|
| K230 与 C07A 两路通信 | USART1/2/3、UART4/5 均在 LQFP-64 管脚表中出现。 | 可行性存在；具体两路 UART、DMA 通道、电平和排针待冻结。 |
| D36A STEP | 多个定时器通道可从 PA/PB 引出。 | 必须选择硬件定时器输出；当前不选具体脚。 |
| MS42CG A/B | 定时器编码器模式可用。 | 必须避开板载/调试资源后再选择。 |
| MS42CG PWM | 定时器输入捕获可用。 | PWM 是否使用及其电平/周期尚未确认。 |
| 控制 tick / 看门狗 | 通用定时器 + IWDG 可用。 | 阶段 2 先独立验证，不能依赖旧例程。 |

## 5. 禁止直接复用的资料内容

- 厂家 LCD 示例的 `STM32F103C8` 设备选择、`0x10000` Flash、`startup_stm32f10x_md.s` 和 LCD 引脚配置；
- 示例中对 USB、CH340、按键、LED、25Q16 的任何未实测假设；
- 原理图中 `STM32F103RE` 的容量标记；
- 任何由“排针存在”推导出的项目接线。

## 6. 阶段 2 最小验收顺序

1. 拍照记录实物芯片完整丝印、两 USB 口/JP5 丝印、BOOT 和 RESET 按键位置；确认无 D36A、MS42CG、K230 或电机连接。
2. 用 ST-Link 接 `3V3/GND/SWDIO/SWCLK`，读取芯片 ID 和 Flash 容量；记录下载、冷启动和复位结果。
3. 新建空白 `STM32F103RC` 高密度工程，仅验证时钟、LED/GPIO、一个定时器 tick、USART1 日志和 IWDG 安全复位。
4. 两路 UART、DMA 与周期抖动通过后，才讨论 D36A 开环台架的正式 IO 方案。
