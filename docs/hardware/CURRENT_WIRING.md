# 当前纯循迹接线表（C07A V1.1 + S27F）

> 范围：只覆盖 `c07a-line-tracker-preferred-20260731` 所需的 C07A/S27F、D103A/TB6612、两轮与其编码器、CD4051 灰度、BLS、LED，以及已占用但未参与控制的 OLED/UART 调试接口。STM32F103RCT6、D36A、MS42CG 和 K230 尚未进入本表。
>
> 真值依据：[`C07A_S27F_LINE_TRACKER_HARDWARE.md`](C07A_S27F_LINE_TRACKER_HARDWARE.md) 与基线的 `h2026_q2.syscfg` / `MEASURED_HARDWARE.md`；“实测”仅代表已记录的车上结果，不代表赛题整圈通过。

## 1. 连接与功能表

| 子系统 | 模块端/信号 | C07A / S27F 网络或引脚 | 用途与当前状态 | 证据与边界 |
|---|---|---|---|---|
| 供电 | P03B → C07A/S27F 逻辑电源 | 由底板供电路径承载 | 当前控制器/底板供电。 | P03B 拓扑见 [`P03B_POWER_MODULE.md`](P03B_POWER_MODULE.md)；电池规格、保险和温升仍为 Q-006。 |
| 供电 | P03B 5 V/GND → CD4051 灰度模块 | 5 V、公共 GND | 当前传感器供电。 | 模块 OUT 接入 MCU 前必须不超过 MCU VDD；不得仅凭本表推断板端针序。 |
| 灰度 | AD2 | `PA12` | CD4051 通道选择 bit2。 | 启动初值 0。 |
| 灰度 | AD1 | `PA27` | CD4051 通道选择 bit1。 | 启动初值 0。 |
| 灰度 | AD0 | `PB16` | CD4051 通道选择 bit0。 | 启动初值 0。 |
| 灰度 | OUT | `PB17 / ADC1_A1_4` | 采样通道 `R0…R7`；地址 `000…111`。 | 代码每路弃首样、再平均 4 次；黑线为高 ADC。 |
| 左轮 | TB6612 **B** PWMB | `PB3 / TIMA1_CCP1` | 左轮 PWM。 | 用户确认、台架验证：物理左轮=B；正占空比为物理前进。 |
| 左轮 | TB6612 B IN1 / IN2 | `PA16` / `PA17` | 左轮方向。 | 上电均为低；`00` 为滑行。 |
| 右轮 | TB6612 **A** PWMA | `PB2 / TIMA1_CCP0` | 右轮 PWM。 | 用户确认、台架验证：物理右轮=A；正占空比为物理前进。 |
| 右轮 | TB6612 A IN1 / IN2 | `PA14` / `PA13` | 右轮方向。 | 上电均为低；`00` 为滑行。 |
| 左轮编码器 | A / B | `PB20` / `PB24` | 左轮四沿正交计数，仅作诊断/影子速度环。 | 属于 TB B 物理左轮；不影响当前主循迹输出。 |
| 右轮编码器 | A / B | `PA25` / `PA26` | 右轮四沿正交计数，仅作诊断/影子速度环。 | 属于 TB A 物理右轮；不影响当前主循迹输出。 |
| 启停 | BLS | `PA18` | 短按松手：`WAIT→RUN` 或故障复位；约 1 s 长按：停车。 | 外部 `47 kΩ` 下拉；松开=0、按下=1；不启用内部上下拉。 |
| 状态 | LED | `PB9` | RUN 常亮、WAIT 慢闪、FAULT 快闪。 | 当前唯一状态提示。 |
| OLED | SDA / SCL | `PA0 / PA1 (I2C0)` | 物理存在、地址 `0x3C`；纯循迹不刷新。 | 已占用配置资源，非当前控制功能。 |
| 调试 | UART0 TX / RX | `PA10` / `PA11` | 115200 调试串口。 | 仅调试；不是赛题图传/主机通信接口。 |
| 调试 | SWD | C07A 板上调试接口 | 下载、断点与观测。 | 不计入业务 IO；接入时保持与动力系统共地且注意防短路。 |

## 2. 已核实的逻辑与安全态

| 时机 | 必须状态 |
|---|---|
| 上电/初始化 | TB6612 两通道 `IN1=0, IN2=0`，PWM=0，电机滑行；软件未 arm。 |
| 进入 RUN | 先 `motor_arm(true)`，再输出左右有符号占空比。 |
| WAIT、FAULT、长按停止或控制超时 | PWM=0、两对方向均 `00`、软件 disarm；不保持驱动。 |
| 电机正反转切换 | 先强制至少一个完整 5 ms 控制周期的 `00` 滑行，再允许反向 PWM。 |
| 灰度扫描 | `AD2/AD1/AD0=000…111` 对应 `R0…R7`；每路 100 µs 建立、丢弃一次 ADC、平均后续 4 次。 |

## 3. 未冻结或禁止推断的内容

- 不以本表确定电池电压、线规、保险、D103A 电机端接线颜色、MG513XP28 CPR/减速比或堵转电流。
- 赛题对当前 CD4051 灰度循迹模块的允许性已由用户转述赛区确认；但精确商品型号、光学元件和板端针序仍不以猜测补全。
- OLED 虽有总线资源，但当前纯循迹不显示赛题计时；因此不得声称已经满足 H-R02 的“启动即计时并显示时间”。
- 将来接入 STM32F103RCT6、D36A、MS42CG、K230 时必须新建对应接线表和 IO 审查，不能挪用或覆盖本表。
