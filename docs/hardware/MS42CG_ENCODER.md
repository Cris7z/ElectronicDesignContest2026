# MS42CG 编码器技术文档

> 适用范围：球杆机构使用的 MS42CG 步进电机编码器；资料版本 V2.0（2026-07）。
>
> 当前阶段：未来球杆反馈资料。**不接入当前纯循迹车，不分配 C07A IO，不导入厂家示例代码。**

## 1. 确认结论

| 项目 | 结论 |
|---|---|
| 型号 | MS42CG；由 `MS42CG使用手册-20260730.pdf` 确认。 |
| 编码器 | MT6816。 |
| 默认输出 | `A`、`B`、`PWM`、`Z`；供电 `VCC/GND`。 |
| 供电 | `VCC=3.3–5.0 V` 输入。为与 C07A 逻辑兼容，未来设计优先统一为 3.3 V，未验证前不得使用 5 V 信号直连。 |
| A/B | 1024 线/转的增量式正交信号；四倍频得到 4096 计数/转。 |
| PWM | 单圈绝对角度 0–360°；占空比与角度成正比。 |
| Z | 每转一次高电平触发，代表固定机械点位；重新上电后该机械点不变。 |

## 2. 编码器连接器

以下顺序严格以手册第 4 页“编码器引脚说明图”的**图示视角**为准：从图中连接器左至右为 `GND`、`Z`、`PWM`、`B`、`A`、`VCC`。接线前仍须以实物插头、线束和极性缺口复核，不能只按线色推断。

| 引脚 | 方向 | 电平范围 | 用途 |
|---|---|---|---|
| `VCC` | 输入 | 3.3–5.0 V | 编码器供电。 |
| `GND` | — | 0 V | 信号参考地。 |
| `A` | 输出 | 0–VCC | 增量式正交相 A。 |
| `B` | 输出 | 0–VCC | 增量式正交相 B。 |
| `PWM` | 输出 | 0–VCC | 单圈绝对角度 PWM。 |
| `Z` | 输出 | 0–VCC | 每转一次的零位脉冲。 |

## 3. 与 D36A、当前车的边界

- D36A 只驱动步进电机线圈；MS42CG 的六针编码器接口不接 D36A 控制排针。
- 当前纯循迹工程已经使用 PB2、PB3、PA12 等资源。MS42CG 手册第 5 页的旧 C03C 示例（`PB6/PB7/PA6/PA12`）仅用于说明，不是本项目 IO 方案，**禁止照搬**。
- 若未来采用 A/B、PWM、Z 的默认模式，应先确定保留哪些反馈量，完成 C07A V1.1 + S27F 的复用冲突审查、信号电平验证和失能安全设计，再提出正式 IO 方案。

## 4. SPI 模式

手册说明可通过拆焊/移焊板上元件把编码器改为 SPI，读取 14 位原始数据；这是硬件改造，不是软件开关。当前禁止改造。若将来确有精度需求，必须先记录电机实物 PCB 版本、改造前照片、SPI 电平和总线冲突，并由用户确认后再操作。

## 5. 后续台架验收

1. 在不接 D36A 的情况下，以 3.3 V 单独给编码器供电，确认静态电流与输出电平。
2. 手动缓慢转动，示波器/逻辑分析仪验证 A/B 相序、Z 单圈脉冲和 PWM 周期/占空比。
3. 对照机械零位，建立 Z、PWM 角度与球杆实际角度的标定关系。
4. D36A 低电流台架联动时，核对方向、丢步、振动和角度回差；未验证前不得闭环控制球杆。
