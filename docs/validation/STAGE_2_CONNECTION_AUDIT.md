## 保留原则

已经接好的线束以实物为准逐根核对。没有以下冲突就标记 `KEEP` 并保持原样：供电回灌或电压不匹配、未共地、同一引脚/定时器重复占用、SWD 冲突、输出互相对驱、D36A 上电默认使能。发现冲突时停止通电，记为 `CONFLICT`，不得为了赶进度直接试机。

本记录只做台架准入检查，不向 `CURRENT_WIRING.md` 或 `CURRENT_IO_OWNERSHIP.md` 写入未验证的 STM32、D36A、MS42CG、K230 正式 IO。

用户于 2026-08-01 确认：当前实物中 C07A 与 STM32 **不通信**；已接的其余线束以现状保留为优先。后续只在发现供电、电平、共地、调试口、默认使能或引脚复用冲突时改变对应单根线，不因接线表整理而重接。

1. 现有线束保持原位，轮电机和步进电机动力电源保持关闭；不要同时接入尚未核对的多路供电。
2. 先只把 ST-Link 的 USB 和 STM32 板的已知 USB 口接到电脑。JP5 的 `3V3/GND/SWDIO/SWCLK` 物理顺序未按实物丝印确认前，不插 SWD 排线。
3. 运行只读预检并记录输出；随后根据实物照片/丝印逐根填表。
4. 接线全部为 `KEEP`、编程器可用后，才读取芯片 ID/Flash 容量；该项已完成，仍不擦除、不烧录。
