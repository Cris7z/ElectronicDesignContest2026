# 控制、协议与调参

## 数据协议

K230 每个有效检测帧向 STM32 UART1 发送一条 ASCII 帧：

```text
$B,SEQ,POS_MM,CONF*XOR\r\n
```

- `SEQ`：0–255 循环帧序号；重复帧不刷新看门狗。
- `POS_MM`：以摆杆 O 点为零的有符号整数毫米值。
- `CONF`：0–100 的置信度百分比。
- `XOR`：对 `B,SEQ,POS_MM,CONF` 每个 ASCII 字节异或得到的两位十六进制校验。

K230 与 STM32都把有效阈值设为 `0.40 / 40`。STM32 超过 150 ms 未收到新的有效帧会停止 STEP 输出并进入故障状态；复位后重新等待 5 个有效帧再使能闭环。

## 控制结构

1. **视觉状态估计**：K230 约 30 FPS 给出位置。STM32 每 5 ms 预测位置，只有收到新序号时才用 alpha-beta 观测器校正速度；加速度来自低通后的速度变化，避免直接对视觉位置二阶差分放大噪声。
2. **预测型球位置外环**：使用约 70 ms 前视位置和速度、加速度制动修正，输出受限的电机轴目标位置偏移（最大 ±120 编码器计数）。
3. **MS42CG 内位置环**：根据 A/B 正交编码器计数追踪电机目标，输出带加减速限制的 D36A RPM 与方向；反向时强制先降到 0 RPM。
4. **中心静止带**：预测位置在 ±8 mm 且速度不超过 12 mm/s 时目标偏移置零，留出满足 ±1 cm 要求的裕量并降低抖动。

静态居中目标没有来自车辆加速度的外部前馈输入；因此该工作点的真实基座加速度前馈为零。这里的加速度项用于对钢球当前加速趋势做预测制动，不等价于移动小车时的 IMU/底盘加速度前馈。

## 主要参数

参数位于 `stm32_keil/USER/main_d36a_test.c`：

| 参数 | 当前值 | 含义 |
|---|---:|---|
| `MOTOR_MICROSTEP` | 16 | 必须与 D36A 拨码一致 |
| `MOTOR_RPM_MAX` | 18 RPM | 内环输出限幅 |
| `VISION_TIMEOUT_MS` | 150 ms | 视觉安全超时 |
| `CENTER_DEADBAND_MM` | 8 mm | 中心静止带 |
| `LOOKAHEAD_MS` | 70 ms | 视觉/执行延迟前视 |
| `OUTER_KP_COUNT_MM_X100` | 550 | 位置外环刚度 |
| `OUTER_KV_COUNT_MMS_X100` | 90 | 速度制动 |
| `OUTER_KA_COUNT_MMSS_X100` | 2 | 低带宽加速度制动 |
| `MAX_MOTOR_OFFSET_COUNTS` | 120 | 摆杆目标位置限幅 |
| `INNER_KP_RPM_COUNT_X100` | 18 | MS42CG 内位置环比例增益 |

## 调试顺序

1. **先确认方向**：短时手动命令正方向，观察 MS42CG 计数符号和球的实际运动。电机编码器符号错，改 `ENCODER_CW_SIGN`；球因摆杆倾斜的运动方向错，改 `BALL_TILT_SIGN`。一次只改一个。
2. **只调内环**：遮挡 K230、保持安全低速，确认编码器反馈存在且电机能稳定回到小位移目标。若明显超调/来回摆，先减小 `INNER_KP_RPM_COUNT_X100` 或 `MOTOR_RPM_MAX`。
3. **调位置外环**：从较小 `OUTER_KP` 开始，逐步增大到有足够纠偏力；若冲过中心，先提高 `OUTER_KV`，再小幅提高 `OUTER_KA` 或 `LOOKAHEAD_MS`。若接近中心抖动，降低 `OUTER_KP` 或增加静止带，而不是加积分。
4. **校准视觉**：将球分别放在已知位置，检查 K230 叠加的 `X=` 与尺子一致。校正 `deploy_config.json` 的左右参考像素与厘米值后再运行闭环。
5. **验收记录**：记录从静止开始到 +5 cm、折返、-5 cm 的总时长，以及两端最大绝对误差。不要以预览画面帧率代替控制数据链路验证。

## K230 模型和校准文件

`deploy_config.json` 含当前相机安装条件下的模型名、阈值和左右端像素标定。提交中不包含 `.kmodel` 二进制、训练数据、图片样本或 Wi-Fi 凭据。运行前必须把同名模型文件放在 K230 的 `/sdcard/mp_deployment_source/`，并根据实际相机位置重新标定。
