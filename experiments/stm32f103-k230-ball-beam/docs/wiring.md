# 台架接线表

本表只适用于本目录的 **STM32F103C8T6 台架工程**。它与仓库主分支的 C07A/MSPM0G3507 整车接线不同，不能混用。

## 1. 供电与接地

| 设备 | 连接 | 要求 |
|---|---|---|
| D36A 动力输入 | 独立、满足电机额定电压/电流的直流电源 | 先断动力检查信号，再接动力 |
| 42 步进电机 | 接 D36A 的电机 A/B 输出端 | 不要带电插拔 |
| STM32F103C8T6 | USB 或稳定 3.3 V 逻辑电源 | 不从 D36A 给 STM32 供电 |
| K230 | Type-C 5 V | 不从 GPIO/UART 排针取电 |
| MS42CG | STM32 的 3.3 V 与 GND | **禁止 5 V** |
| 信号参考地 | STM32 GND、K230 GND、D36A 信号 GND 相连 | 用单点/短粗线接到动力地；电机大电流回流不要走信号线 |

## 2. STM32 到 D36A（通道 1）

| STM32F103C8T6 | 外设功能 | D36A | 说明 |
|---|---|---|---|
| PB6 | TIM4_CH1 PWM | ST1 | STEP 脉冲 |
| PB8 | GPIO 输出 | EN1 | 本工程高电平使能 |
| PB9 | GPIO 输出 | DIR1 | 方向 |
| GND | 地 | GND | 必须接 |

本程序只使用 D36A 的通道 1；`ST2/EN2/DIR2` 不接。D36A 的电机端 A/B 接 42 步进电机对应的两相线。若电机抖动不转，先断电后按电机线对识别两组线圈，再接至 A、B 两相。

### D36A 拨码

代码设定为 `MOTOR_MICROSTEP = 16`，因此拨码必须让通道 1 实际工作在 **1/16 细分**。D36A 的细分和电流拨码随板卡版本/丝印定义，应以随板说明书的表格为准；不要仅根据开关朝向猜测。电流先选不超过步进电机额定相电流的较低安全档，验证温升和力矩后再调整。

## 3. MS42CG 编码器到 STM32

| MS42CG 信号/线号 | STM32F103C8T6 | 外设功能 | 本工程用途 |
|---|---|---|---|
| VCC（12） | 3.3 V | 供电 | 编码器逻辑供电 |
| GND（7） | GND | 地 | 与 STM32、D36A、K230 共地 |
| A（11） | PA0 | TIM2_CH1 | A/B 正交计数 |
| B（10） | PA1 | TIM2_CH2 | A/B 正交计数 |
| PWM（9） | PA6 | TIM3_CH1 | 绝对角 PWM 捕获；当前控制器主要用 A/B |
| Z（8） | PA12 | EXTI12 | 每转零位脉冲计数 |

线号来自当前使用的 MS42CG 线束定义；如线束标签与此不同，以传感器实际丝印/说明书为准。A/B 方向相反时不要换乱电源线，可在代码中调整 `ENCODER_CW_SIGN`。

## 4. K230 到 STM32（单向 UART）

| 01Studio CanMV K230 | STM32F103C8T6 | 说明 |
|---|---|---|
| 物理针脚 8，TX1 / GPIO3 | PA10，USART1_RX | 115200、8N1；K230 发送球位置 |
| GND（任一排针 GND，例如物理针脚 6/9/14） | GND | 必须共地 |
| 物理针脚 10，RX1 / GPIO4 | 不接（可选接 PA9） | 当前协议单向，不需要 |
| 5V/3.3V | 不接 | 两板各自供电，不经 UART 排针供电 |

两端均为 3.3 V 逻辑，无需电平转换。若改用双向 UART，才将 STM32 `PA9/USART1_TX` 接 K230 `RX1/GPIO4`，且仍不连接任一电源针。

## 5. STM32 调试与未占用引脚

| 引脚 | 当前用途 |
|---|---|
| PA9 | USART1_TX，串口日志/可选 K230 回传 |
| PA10 | K230 UART1 接收 |
| PB6 | D36A STEP，不能再用作 I2C SCL |
| PB8/PB9 | D36A EN/DIR |
| PA0/PA1 | MS42CG A/B，不能再用于 ADC/I2C |
| PA6 | MS42CG PWM |
| PA12 | MS42CG Z |

## 上电前检查顺序

1. 不接 D36A 动力：确认 STM32、K230 都可独立启动，且三者地线相通。
2. 用示波器/逻辑分析仪确认 PB6 有步进脉冲、PB8 使能和 PB9 方向变化。
3. 只接 MS42CG 3.3 V，手动转轴检查 A/B 计数及 Z/PWM 信号。
4. 接步进动力，低速确认摆杆实际方向；再接 K230 UART 与视觉闭环。
